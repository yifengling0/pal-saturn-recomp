# 鸿蒙中文触控与布局编辑复测

本批提供较大的触摸布局、中文宿主设置、六组位置编辑及退出确认。先前设备上已经通过的透明度/大小/返回/画面切换/配置持久化仍作为已有事实；本批新功能在 Linux 实际 C++/SDL 合成界面和受控事件中验证，未取得本批 HAP 或设备通过结论。

## 怎么用

- 默认菜单键移动到下方 START 旁；手机较窄时 L / START / 菜单 / R 排在下方控制组附近。
- 点菜单→“大小”“间距”“透明度”调整手感。六个 ABC/XYZ 同尺寸，L/R 对齐，十字键与右侧按钮不再只按很小的旧百分比布局。
- 点“移动按键”，拖动十字键、六按钮组、L、R、START 或菜单中的任意一组。
- “完成”才保存位置；“取消”、系统返回或手柄 B 放弃本次位置变化，恢复进入编辑前的布局。编辑时游戏暂停，不把拖动发成游戏方向/按钮。
- 编辑页“重置位置”仅重置正在编辑的位置，仍需点完成保存；设置页“重置触控”重置触控大小、间距、透明度和位置，不改画面、键盘或手柄绑定。
- 菜单键独立于显示游戏按键，即使关闭整套虚拟手柄，仍保留菜单入口。自定义组重叠时，菜单键优先命中；如拖乱，可由编辑页取消/重置恢复。

大小和透明度当前是整套触控参数，位置按六组编辑；不含每个 ABCXYZ 单键独立大小、双指缩放、吸附网格或系统边缘滑入手势。

## 铺满画面

“画面”可选保留原电视样式、保持比例适配、拉伸铺满。保持比例可能留黑边；拉伸铺满会改变宽高比例，但不为了填满而裁掉对白。游戏图像本身的黑色房间边界仍是画面内容，不会被当成系统黑边裁掉。

控制按 renderer 输出像素布局并结合显示密度；菜单命中框在已测矩阵中至少 48 逻辑单位。边缘有呼吸间距，但平台真实安全区/系统手势 inset 仍标为未核实，不能把合成零 inset 当作鸿蒙设备适配完成。铺满模式没有额外黑边可放按键，按键会半透明覆盖屏幕边缘，可按个人习惯移动。

## 保存与兼容

已有明确的大小、透明度、样式与画面配置保留，不因升级全部重置。新增 `[touch]` 的 dpad_x/y、face_x/y、left_x/y、right_x/y、start_x/y、menu_x/y；取值 -1 表示自动位置，0–10000 表示扣除完整按键组边界后可用中心区间中的位置。旋转、改变大小或分辨率后重新约束整组，不把一半按钮放出屏幕；单纯旋转不会偷偷写入新位置。

手指抬起、失焦、切后台和输出尺寸改变会结束拖动。第二根手指不能抢走正在拖动的组或误触工具栏。允许用户主动把按键组互相覆盖，没有自动避碰求解。

退出游戏增加二次确认，默认选择取消。提示退出不会自动保存剧情，请先在游戏内存盘。宿主写入已有 BUP 与调用游戏存档菜单不是同一件事，本批不强行伪造剧情自动保存。

## 中文字体与平台

中文仅用于 Harmony 宿主暂停菜单和布局编辑；游戏本身文字与高级 ImGui launcher 不改。桌面默认仍英文。字体为 Noto Sans CJK SC 的重命名、小范围 OFL 子集，未使用游戏提取字体。对应许可证、来源哈希、生成方法与字形清单保存在 runtime 的 `third_party/pal-menu-cjk/`；分发 HAP 或其他二进制时须同时保留该目录的 LICENSE.txt 到第三方声明。字体内也嵌入完整许可证。

## 建议真机验收

1. 同场景比较默认大小，确认下方菜单和 START 都能舒适点到。
2. 移动六组，取消一次、完成一次，退出重启核保存。
3. 改透明度/大小后旋转或改变窗口，核完整按键不出界；既有手柄和键盘配置不变。
4. 编辑时按住/拖动/第二指触碰、切后台再恢复，确认游戏人物没有意外移动或残留方向。
5. 关闭整套虚拟按键仍能打开菜单；进入退出确认先取消再正常退出。
6. 保持比例与拉伸铺满分别核实际输出区域、对白完整性及系统导航手势边缘。

本地合成界面截图均标为 synthetic，不应作为鸿蒙真机截图。代码参考了 VintagePomeloPro 的归一化位置与保存/取消交互设计，没有复制其框架或增加 Wine/evdev 依赖。

## 更新构建

本批新增 0011 补丁，必须保留旧 patched checkout 后重新 setup 和生成。沿用 `HARMONY_AUDIO_GAMEPAD_SHORTCUTS.md` 的重建步骤，把唯一备份目录名改为 `saturn-recomp-pal.before-0011`；已存在时另起名称，不能覆盖。重新 `build --recompile` 后才可 `ohosbuild.py --skip-learn`。缺失/陈旧 helper 或字体/UI 文件会被身份守卫拒绝；不要删守卫、手改哈希或仅拿旧 runtime 重打 HAP。
