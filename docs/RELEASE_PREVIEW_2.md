# v0.1.0-preview.2 三平台发行

本次发行以 `b4d3cec9467131d02b1058a3a4077bd56109817e` 的运行代码为基准。
发行提交仅修正打包说明、历史快捷键文档并增加对应文案回归；不改变运行代码。
三平台二进制的构建输入、SHA256、文件清单和最终源码提交见资产旁的
`RELEASE-PROVENANCE.json` 与 `SHA256SUMS.txt`。

## 使用

- Windows x64：解压 ZIP，在 `disc/` 放入自己有权使用的完整 BIN+CUE，运行 `run.bat`。
- Linux x86_64：解压 tar.gz，在 `disc/` 放入相同合法镜像，运行 `./run.sh`。
  需要 glibc 2.38 或更新、图形桌面与正常 OpenGL 驱动；包中带 SDL3、libstdc++、libgcc_s。
- OHOS：下载未签名 debug HAP（ARM64+x86_64）。须在自己的 DevEco/设备环境签名后安装；
  未签名包不能直接当作已签名安装包。当前包名是 `com.palhero.palsaturn`。在支持下载目录
  权限的设备上，首次运行授权后，将合法镜像放在
  `Download/com.palhero.palsaturn/disc/`；其他设备需按应用沙盒路径/DevEco部署流程准备。
  当前产物的真机安装、触摸、音频和手柄没有在云端重新验证。

验证光盘版本是台湾土星版 T-37401H V1.000，areas JT。使用单个 BIN，
CUE 描述第1条 MODE1/2352 数据轨和第2–13条 CD-DA 音轨。CUE 与 BIN 不必同名，
但 CUE 内的 FILE 引用必须匹配实际 BIN 文件名；Linux区分大小写。
BIN SHA256：`4c76366e3178289c3e73264d8f3a0b9b8b3d78f7baa0862561ce48ce4199d4b5`。

## 本次功能

- 场景切换后保持按住方向的连续性；修复地图 S/W/Q 快捷菜单。
- 战斗 W 投掷、D 防御、A 原生普通攻击围攻；A 保留先前角色已选指令，Esc 取消连续围攻。
- F 保留原生最强法术选择，R 重复上轮指令；A 与 F 不再混用。
- 保留用户自己的配置与存档；发行包只带干净默认配置，没有个人进度。

## 验证边界

Linux 同源生产程序已用实际 SDL 键盘事件验证 W/D/A/F/R、投掷物消耗、战斗胜利、
场景存档和重新读档。本次发行增加完整打包回归、源输入一致性验证和发行目录的
依赖/启动帮助/无光盘退出检查。Windows 是同源交叉编译与 PE/DLL 静态检查；
OHOS 已完成双 ABI 编译、链接与 HAP 结构检查。用户表示已本地测试，但未说明平台，
此确认不扩写为三端全部真机通过。完整工具测试结果与未跑项目随发行清单列明。
