# 游戏中设置与启动设置的边界

游戏中点击菜单，可直接调整画面模式、触摸按键显示、大小、间距、透明度、配色与位置。布局编辑中的“完成”保存位置，“取消”放弃本次草稿；退出游戏仍须先在游戏内存盘。

## 当前没有独立“高级启动器”页

现有高级 launcher 在创建游戏机器之前运行，不是可在游戏中安全打开的暂停面板。把它直接插入暂停流程可能重新初始化机器或丢失当前未保存进度。本批不建立内容重复的空页面。

- 运行中键盘/手柄重新绑定、死区捕获与冲突处理界面尚未提供。先验证默认映射和实体手柄桥接，再独立增加重绑界面。
- 音量配置目前在音频流初始化时设置增益，尚无本批验证过的实时音量调节链。
- 镜像、机器配置及启动参数应在退出游戏后配置。Harmony 的 advanced.txt 是启动时读取的参数文件，并不意味着已有从游戏中滑出、编辑、返回原进度的 launcher。
- 宿主正常退出会持久化已经形成的备份数据，但不自动调用游戏剧情存盘，也不自动产生完整机器即时存档。

现有菜单入口、位置编辑与后续可选边缘手势均复用暂停流程；不能将它们描述为完整高级 launcher。没有真机验证的系统边缘事件分发或安全区表现仍需本地设备确认。
