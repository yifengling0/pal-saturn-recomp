## 0. 边界（先说清楚）

- 本轮**没有**进入任何可操作地图，因此**没有任何位移、动画、镜头数据**。
- 指导文档第 2.1 节的五类成因（逻辑速度 / 动画节奏 / 方向投影 / 画面表现 / 同步逻辑）
  **全部处于"待测"**；本报告不指定根因，不给任何坐标乘数、帧率或速度常数。
- `validation/pal_validate/walking.py` 的 CSV 指标仍是**合成夹具**，只证明计算逻辑，不构成游戏证据。
- 不预设土星版是 30 FPS。土星版逻辑 tick 与 VBlank 的比例必须实测（用 `--watch` + VBlank 计数）。

## 1. 采集协议（进入游戏后执行）

固定初始状态 → 单一方向输入 → 按 VBlank 采样 → 从写入地址反查 native 函数 → 分离"逻辑位移 / 动画索引 / 渲染位置"。

| 步 | 动作 | Windows 可用通道 | 说明 |
|---|---|---|---|
| 1 | 固定初始存档 | `--save <文件>` 或 `--save -` | 测试专用存档，绝不覆盖玩家存档 |
| 2 | 固定起始坐标 | `--write VBLANK:ADDR=HEX` | 需先证明该地址是逻辑坐标（下条） |
| 3 | 回放输入 | `--input "V:UP,V:..."` 或 `--input @脚本` | 已验证可解析；`--record-input` 在窗口模式录真实按键 |
| 4 | 采样 | `--watch LO:HI`、`--peek ADDR:WORDS`、`--watch-vblanks FROM:TO` | 已验证（P1 用它证明了拷贝未发生） |
| 5 | 反查写入者 | `--watch` 输出的"function:addr"归属 | 已验证：能定位到 native 函数与调用点 |
| 6 | 截图对齐 | `--shot N,...`、`--dump N,...` | PNG/VRAM 导出可用 |
| 7 | 覆盖率 | `--coverage cov.txt` | 判定哪些函数真的跑过 |
| 8 | 状态转移 | `--state-out/--state-in/--checkpoint` | 用于反复从同一点重放 |
