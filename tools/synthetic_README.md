# Linux 合成程序验收

这些测试全部使用本仓库新编写的 SH-2 指令、数学向量和最小 ISO9660/CUE
夹具，不包含游戏程序、游戏美术、音轨、BIOS 或厂商安全启动代码。
它们验证构建和最小运行通路，**不能证明《仙剑奇侠传》土星版已启动或可玩**。

## 复现

先按 `docs/LINUX_CLOUD_BUILD.md` 安装构建依赖并准备已授权执行的运行时：
干净解析器位于 `third_party/saturn-recomp`；`086c372` 加仓库 `0001–0004`
补丁的运行时位于 `third_party/saturn-recomp-pal`，使用 editable 安装。

在仓库根目录执行：

```sh
build/venv/bin/python tools/synthetic_tests.py
build/venv/bin/python tools/synthetic_check.py --jobs 2
```

每次集成都新建 `build/synthetic/<UTC时间>/`，不复用主验收目录的生成文件或
目标文件。也可用 `--out build/synthetic/<新的目录名>`，已有目录或其他位置
会被拒绝。不要使用 `python -O` 或 `PYTHONOPTIMIZE`，这会被脚本拒绝。

生成器、编译器和运行时每一步的完整命令、输出和退出码都保存在 `logs/`。
`provenance.json` 记录运行时完整提交、工作树差异哈希、四个补丁哈希、脚本
哈希和 Python 版本。只有全部检查通过才写出 `summary.json`。任何非预期
退出码、证据缺失、超时、像素差异或输入变更都使整个命令失败。

全部运行使用 `--save -`、隔离的 `HOME/XDG_DATA_HOME/XDG_CONFIG_HOME`、
独立输出目录；测试前后校验输入 SHA-256，并确认没有生成 `backup.bin`。

## 实际覆盖

1. 8 项夹具/数学边界单测，不需要执行第三方运行时。
2. 16 个自写 SH-2 算术函数，11,296 组向量：每函数 450 组边界值/进位组合
   和 256 组固定种子随机值。包括加减、位操作、进借位、移位、旋转、有符号
   溢出、有符号/无符号比较、乘法低 32 位。检查 22 个寄存器和两块 WRAM CRC。
   期望值由独立 Python 整数数学计算，没有使用 `sh2emu` 或上游向量生成器。
3. 干净解析器读取最小 ISO 的头部和目录；补丁版运行时完成 CUE → ISO9660 →
   首读文件 → 模块 CRC 识别 → SH-2 重编译执行 → WRAM 标记 → VDP2 back-screen
   写入 → 10 VBlank 停止。重复两次，每次验证第 2 和第 10 帧。
4. 4 项必须失败的负向测试，并同时核验退出码和对应诊断：
   - 人为错误的数学期望：退出 1，准确报告 1 个失败向量。
   - selftest 未知入口 `060F0000`：退出 1，报告 non-entry。
   - headless 程序跳入未知入口 `060F0000`：退出 1，报告非活动模块入口。
   - 镜像程序内容与编译模块不匹配：退出 2，拒绝首读文件。

## 与实际游戏的差距

这只是单核、自写循环和固定 VDP2 底色。没有执行游戏剧情、走路逻辑、动态
叠加模块、手柄输入、CD 数据块命令、68000 音频程序、VDP1 绘制、NBG 图层或
RBG0/RBG1 旋转合成；没有做参考模拟器/硬件画面对照。日志中的 `0 draws`、
`0 not silent` 也反映这一范围。即使本集全绿，游戏的旋转背景黑屏问题仍需
独立修复，并用用户提供且已校验的合法本地游戏资产重跑真正的场景验收。
