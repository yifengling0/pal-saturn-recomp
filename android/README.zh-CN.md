# Android ARM64 移植

## 导入资源

APK **不含游戏光盘**。准备自己合法拥有的仙剑土星台版 `T-37401H V1.000` 完整原盘：1 个 CUE、它引用的全部 BIN，共 **13 轨（1 数据轨 + 12 CD-DA 音轨）**。

1. 把文件放在手机可由系统“文件”选择器访问的位置（例如 Download 下单独的 PAL 文件夹）。压缩包必须先自行解压。
2. 启动应用，选择“选择资源文件夹”；选到包含 CUE/BIN 的目录并授权。或用“选择 CUE + 全部 BIN”一次多选同目录下全部文件。
3. 请把CUE放在所选资源目录根部；向下子目录引用使用文件夹入口。当前不接受含 `../` 的上级/兄弟目录引用（即使仍在所选树内）；这类原盘请先整理为同目录CUE/BIN并相应修正CUE文件名引用，不改动BIN内容。大小写会统一匹配；重名冲突、缺轨、非完整扇区或错误版本会拒绝。同时核对原盘13轨的绝对起点和总计243793个扇区（573401136字节）；这不是逐字节内容哈希验证，也不支持所有其他dump布局。当前只支持原盘 raw `MODE1/2352` + `AUDIO` / `BINARY`，不接受虚拟非零 PREGAP/POSTGAP；请用间隙已经包含在 BIN 数据中的原盘。
4. 等待复制完成后点击“开始游戏”。应用私有目录里是真实可随机访问文件，不依赖原内容 URI 长期可读。首次导入需约 550 MiB 空间；更换时须额外留一整份原盘空间，失败/取消不覆盖原有资源。旧代资源暂保留，下一次应用冷启动且游戏未运行时清理；不需要反复清除应用数据。
5. 游戏中使用触控按键或手柄；手机返回键打开游戏菜单。**先从菜单退出游戏再重新导入或导出存档**。

存档与资源完全分开：`files/saves/backup.bin` 为内置备份 RAM，`cartridge.bin` 为记忆卡；更换资源不删除它们。“导出存档 ZIP”经系统保存选择器备份两者及设置（存在时）。卸载应用会删除私有资源和存档，请先备份。此版导出包暂不提供界面恢复入口，保留用于后续迁移；不要清除应用数据作为导入重试办法。

## 构建

依赖官方 Android SDK platform 35 / build-tools 35.0.0、NDK r28c (`28.2.13676358`)、JDK 21、Gradle 8.11.1、Android Gradle Plugin 8.9.2、SDL 3.4.18 (`829a65d769d935c4852f8159e964312c0957260a`)。SDK 许可须由安装者确认。仅构建 arm64-v8a，minSdk 26（Android 8），targetSdk 35。

先按根 README 用自己的原盘完成 preview7 options 源码生成；生成目录必须保留相邻 `recomp/` 和 `runtime/`，并保留私有 `build/disc-extract` 供构建时 identity 检查。不要把原盘、提取数据或构建缓存提交。

`tools/androidbuild.sh` 使用现有已安装 SDK/JDK/Gradle/SDL，不自动下载或接受许可。产物是开发签名 APK，非商店正式签名。源代码中不含签名私钥。

## 验证边界

21项纯 Java 微型布局导入测试（生产固定原盘TOC）包含路径逃逸、缺文件、大小写冲突、版本错、扇区截断、取消及原子替换；私有原盘复制测试只在本地执行，不分发测试盘。APK/ELF 静态验证和设备测试结果以本次交付报告为准，构建成功不能证明手机上的触控、音频或整场游戏已通过。
